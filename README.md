# Орбитакт — исправленный сайт 3.9.5

Готовый статический сайт: новое название, актуальные изображения приложения, режим дыхания перед сном, отметка 16+ и блок «Книга, рассказ и комикс».

## Куда ведут ссылки

- Произведения автора: **https://duckolly.github.io/testofsilence/**. Книга, рассказ «Испытание безмолвием 3025» и комикс размещены на общем авторском сайте, по указанию автора. Отдельные URL и якоря произведений не придуманы.
- Скачать приложение: **download/orbitakt-arm64.apk** — файл 3.9.5+18 включён в этот комплект, поэтому кнопка не зависит от публикации GitHub Release.
- Исходники приложения: https://github.com/Duckolly/orbitakt .
- Поддержка: https://t.me/dvizhoffline . Адрес сообщества сохранён; переименование приложения не меняет Telegram автоматически.

## Как применить фикс

1. Откройте локальную папку **репозитория сайта**. В исходном архиве используется `Duckolly/dvizhoff`; репозиторий приложения `Duckolly/orbitakt` — отдельный проект.
2. Распакуйте **содержимое ZIP прямо в корень репозитория сайта**, где уже находится index.html. Не создавайте дополнительную вложенную папку. Сохраните свою папку .git.
3. Замените index.html, privacy.html, support.html, папку assets и остальные файлы фикса. Важно также добавить папку **download** с APK и обновлённую **.github/workflows/publish-pages.yml**: workflow теперь публикует APK вместе с сайтом.
4. Закоммитьте и отправьте изменения в main. В GitHub → Settings → Pages выберите GitHub Actions, если это ещё не настроено.
5. В Actions дождитесь успешного **Publish Orbitakt site**. Если Pages разворачивается из ветки, обновление файлов тоже подходит: сайт не требует сборки.

ZIP содержит корневой index.html, без внешней папки. Новый VM, сервер или платный хостинг для этого сайта не нужны. Публикация в удалённый репозиторий из этого комплекта не выполнялась. Переименовывать репозиторий сайта ради нового названия приложения не обязательно; при сохранении dvizhoff сохраняется прежний URL сайта.

## Проверить после публикации

- Главная страница показывает «Орбитакт 3.9.5», новую иконку и отметку 16+.
- Кнопка «Скачать APK» загружает файл orbitakt-arm64.apk размером 18 141 739 байт.
- «Автор» открывает блок произведений, а кнопка «Открыть авторский сайт» ведёт точно на https://duckolly.github.io/testofsilence/ .
- Политика и поддержка открываются без 404, копирование шаблона и локальная диагностика работают.
- На телефоне нет горизонтальной прокрутки; ссылки и кнопки доступны.

Ожидаемый адрес при сохранении исходного репозитория: https://duckolly.github.io/dvizhoff/ . Внешние страницы автора, Telegram и GitHub в этой среде не удалось проверить по HTTP; их адреса сохранены согласно указаниям автора.

## Проверки локально

```bash
python -m unittest discover -s tests -v
python tools/site_audit_fix.py . --repo dvizhoff --check
node --check assets/diagnostics.js
node --check assets/support.js
node tests/test_web_diagnostics.js
```

Node.js и Python нужны только для этих проверок, а не для посетителей сайта. В браузере работает статический HTML/CSS/JS без сторонних библиотек, шрифтов и аналитики.

## Состав

- index.html, privacy.html, support.html, assets/, download/, .nojekyll — публичный сайт.
- .github/workflows/ — проверка и публикация GitHub Pages.
- tests/, tools/ — локальные проверки.
- android/ и CURSOR_TASK.md — сохранённые из исходного архива вспомогательные материалы по диагностике Android, а не исходники приложения или подтверждение их внедрения.
- CHANGES.md, VERIFICATION.json — описание исправлений и результатов проверки.

Старый технический ключ браузерной диагностики dvizh_web_diagnostics_v2 сохранён для совместимости существующего журнала. Имя выгружаемого отчёта обновлено на orbitakt-site-diagnostics-YYYY-MM-DD.json.
