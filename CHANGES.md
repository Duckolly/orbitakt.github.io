## Что сделать владельцу

1. Распаковать этот ZIP, загрузить **содержимое корня** в ветку `main` репозитория `dvizhoff`.
2. В Settings → Pages → Source выбрать `GitHub Actions`.
3. В Actions убедиться, что Publish Dvizh site прошёл без ошибок.
4. Открыть опубликованный сайт и проверить страницы `privacy.html`,
   `support.html`, Network, экспорт и удаление журнала.
5. Для диагностики остановки шагомера предоставить исходники **Android-приложения**,
   а не сайт: нынешний архив содержит только шаблон Kotlin.
